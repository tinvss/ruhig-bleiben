# Ruhig bleiben

Ein Handyspiel, das schwerer wird, je hektischer du tippst. Gewinnen heißt ruhig werden.

Einfach `index.html` im Browser öffnen, am besten auf dem Handy hochkant.

`chaos.html` ist eine übertriebene Version mit ganzen Schwärmen aus Nachrichten und Weckern.

`atem.html` steuert sich anders: Halten heißt einatmen (steigen), Loslassen heißt ausatmen (sinken). Dazu kommen Pop-ups wie auf dem Handy, die man nicht antippen darf.
